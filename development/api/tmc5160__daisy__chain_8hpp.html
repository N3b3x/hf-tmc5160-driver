Detailed Description

High-level daisy-chain manager for multiple TMC5160 drivers.

This file provides a TMC5160DaisyChain class that manages multiple TMC5160 drivers on a single SPI bus using daisy-chaining. It handles proper device creation, chain length configuration, and supports dynamic addition/removal of devices.
