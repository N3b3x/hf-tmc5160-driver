Detailed Description

ESP32 SPI implementation of TMC5160 communication interface.

This class provides SPI communication for the TMC5160 using ESP-IDF SPI driver.

Set chip select (CSN) pin state for daisy chaining.

Parameters
csn_pin_indexIndex of the CSN pin (0-based) for multi-chip setups
activetrue to assert CSN (active low), false to deassert
Returns
true if CSN was set successfully

For single-chip setups (index 0), CSN is handled by hardware SPI driver. For multi-chip setups, override this method to control additional CSN pins.
