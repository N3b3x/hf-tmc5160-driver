314 // NOTE: Board has 0.05 Ohm Sense Resistors (1W, low-inductance type required).

316 //
317 // Current Calculation (datasheet formula):
318 // I_RMS = (GLOBAL_SCALER/256) * ((IRUN+1)/32) * (VFS/RSENSE) * (1/√2)
319 // Where VFS = 0.325V (typical full-scale voltage)

328 // Increased to IRUN=20 for better StealthChop calibration:
329 // - IRUN ≥ 8 is minimum for StealthChop automatic tuning
330 // - IRUN 16-31 recommended for best microstep performance
