Detailed Description

template<typename Derived>
class tmc5160::SpiCommInterface< Derived >

CRTP-based SPI implementation of TMC5160CommInterface.

Uses a 4-wire SPI bus (mode 3) to exchange 8-byte datagrams. Data is sent MSB-first, big-endian.

SPI Protocol:

  • Read: Send address (bit 7 = 0), receive 4 bytes + 3 dummy bytes
  • Write: Send address | 0x80 (bit 7 = 1), send 4 bytes

Example usage:

class MySPI : public tmc5160::SpiCommInterface<MySPI> {
public:
CommMode mode() const noexcept { return CommMode::SPI; }
bool spiTransfer(...) { ... }
bool gpioSet(...) { ... }
bool gpioRead(...) { ... }
void debugLog(...) { ... }
void delayMs(...) { ... }
void delayUs(...) { ... }
};
