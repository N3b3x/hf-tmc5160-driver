Detailed Description

Unit conversion functions for TMC51x0 driver (TMC5130 & TMC5160)

This file provides free functions for converting between physical units (millimeters, degrees, RPM) and internal driver units (steps, steps/s). All functions are in the tmc51x0 namespace and follow PascalCase naming.
