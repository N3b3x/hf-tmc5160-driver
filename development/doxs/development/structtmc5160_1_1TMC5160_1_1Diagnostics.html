Check if open load is detected on either phase.

Parameters

phase_bReference to store phase B status (true if open load detected)
Returns
true if read successfully, false otherwise

Convenience method to check both phases at once.

Note
Requirements for reliable detection:
  • Must operate in SpreadCycle mode (StealthChop disabled)
  • Motor must be moving (minimum 4× microstep resolution in single direction)
  • Use low or nominal motor velocity
  • Cannot be detected in standstill (coils may have zero current)
Warning

Perform homing using a reference switch (Section 12.4)

Parameters
directionDirection to search (true = positive, false = negative)
search_speedSpeed for homing search in steps/s
switch_speedSpeed for slow approach to switch in steps/s (unused, reserved for future two-phase approach)
final_positionReference to store final position after homing (will be 0 after successful homing)
use_left_switchtrue to use REFL, false to use REFR
timeout_msMaximum time to wait for switch in milliseconds (default: 10000ms)
Returns
true if switch hit and homing completed successfully, false if timeout or error

Implements complete homing procedure from datasheet section 12.4:

  1. Ensure switch is not pressed (user responsibility - move away before calling)
  2. Activate position latching and motor stop upon switch event
  3. Start motion ramp into direction of switch
  4. Wait for standstill after switch hit (poll VACTUAL/vzero)
  5. Switch to hold mode and calculate position difference
  6. Write difference to actual position register (sets home position to 0)

After successful homing:

  • Motor position is set to 0 (home position)
  • Moving to position 0 will return motor to the switching point
  • Stop function is disabled to allow moving away from switch
Note
Uses hard stop for precise homing (no overshoot)
Ensure switch is not pressed before calling (move away first)
After homing, configure switches for normal operation if needed

Automatically tune StallGuard threshold (SGT)

Parameters
target_velocityVelocity to tune at
final_sgtReference to store the tuned SGT value
min_sgtMinimum SGT to try (default: -10)
max_sgtMaximum SGT to try (default: 63)
accelerationAcceleration/deceleration (default: 3000.0f steps/s^2)
min_velocityMinimum velocity to verify tuning at (0 = disabled)
max_velocityMaximum velocity to verify tuning at (0 = disabled)
velocity_unitUnit for velocity and acceleration parameters (default: Steps)
Returns
true if tuning succeeded, false if failed (e.g., stall never cleared)

Implements the automatic tuning algorithm:

  1. Sets SGT to min_sgt
  2. Accelerates to target_velocity
  3. Monitors SG_RESULT
  4. Increases SGT until SG_RESULT is consistently > 0
  5. Verifies SGT at min_velocity and max_velocity if specified
