Detailed Description

Main TMC5160 stepper motor driver interface and subsystem classes.

This file contains the primary TMC5160 class and all its subsystem interfaces for comprehensive stepper motor control functionality including ramp control, motor configuration, encoder integration, diagnostics, and protection systems.
