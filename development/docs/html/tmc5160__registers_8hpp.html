Detailed Description

Register definitions and bitfield structures for TMC5160 stepper motor driver.

This file contains all register addresses, bit field definitions, and register structures for the TMC5160 stepper motor driver IC. All register definitions are based on the TMC5160 datasheet and cross-referenced with archived driver implementations.
