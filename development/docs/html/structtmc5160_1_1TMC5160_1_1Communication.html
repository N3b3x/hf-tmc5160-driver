Configure UART slave address and send delay.

Parameters
slave_address7-bit slave address (0-127), same as UART node address
send_delayNumber of bit times before replying to register read (0-15), stored locally
Returns
true if configured successfully, false otherwise

Note: Slave address and UART node address are the same value. Send delay is stored locally since SLAVECONF register is write-only.
