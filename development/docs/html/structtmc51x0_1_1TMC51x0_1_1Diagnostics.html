Check if open load is detected on either phase.

Parameters
phase_aReference to store phase A status (true if open load detected)
phase_bReference to store phase B status (true if open load detected)
Returns
true if read successfully, false otherwise

Convenience method to check both phases at once.

Note
Requirements for reliable detection:
  • Must operate in SpreadCycle mode (StealthChop disabled)
  • Motor must be moving (minimum 4× microstep resolution in single direction)
  • Use low or nominal motor velocity
  • Cannot be detected in standstill (coils may have zero current)
Warning
Open load flags are informative only and do not cause driver action. Also triggered by undervoltage, high velocity, short circuit, or overtemperature conditions.
See also
Datasheet section 11.3: Open Load Diagnostics

noexcept

Clear specific bits in RAMP_STAT register.

Parameters
bits_to_clearBits to clear (write 1 to clear corresponding bit)
Returns
true if cleared successfully, false otherwise

RAMP_STAT is a read-write-clear register. Writing 1 to a bit clears it. Common bits to clear:

  • event_stop_sg (bit 0): Stall event flag
  • event_stop_l (bit 1): Left switch event flag
  • event_stop_r (bit 2): Right switch event flag
  • event_pos_reached (bit 3): Position reached flag
  • velocity_reached (bit 4): Velocity reached flag

template<typename CommType >
bool TMC51x0::Diagnostics::SetTcoolthrs ( float threshold,
Unit unit = Unit::RevPerSec )
noexcept

Set TCOOLTHRS register directly.

Parameters
thresholdVelocity threshold in steps/s (0 = disable, max = 0xFFFFF)
Returns
true if set successfully, false otherwise

Sets the lower threshold velocity for CoolStep and StallGuard2. When TSTEP < TCOOLTHRS (velocity > threshold), CoolStep and StallGuard2 are enabled. Setting to 0 disables these features at all speeds.

Note
For high-level configuration, use ConfigureStallGuard() instead.
