Detailed Description

UI implementation with Adafruit 2.9" ThinkInk E-Ink tricolor display.

Display: 2.9" ThinkInk FeatherWing (296x128 pixels horizontal) Orientation: Vertical (128x296 pixels when rotated) Buttons: UP (top), SELECT (middle), DOWN (bottom)

Features:

  • Full menu navigation system
  • Settings editing with value adjustment
  • Proper e-ink tricolor support (black, white, red)
  • Optimized refresh rates for e-ink
