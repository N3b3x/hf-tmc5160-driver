Detailed Description

Communication interfaces for TMC5160 stepper motor driver using SPI and UART.

This file provides comprehensive communication interfaces for the TMC5160 motor driver, supporting both SPI and UART protocols with register read/write operations. It includes GPIO control interfaces and board-agnostic pin management for different hardware implementations.

Compile-Time Configuration

TMC5160_DISABLE_DEBUG_LOGGING: Define this macro to completely disable all debug logging throughout the TMC5160 library. This removes all logging code from the binary at compile time, saving code size and improving performance.

Example usage:

#define TMC5160_DISABLE_DEBUG_LOGGING
#include "tmc5160_comm_interface.hpp"
